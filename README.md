# SolarScripts

Tampermonkey scripts for the team.

## Install

1. Install the [Tampermonkey](https://www.tampermonkey.net/) extension.
2. Open the script's folder below and follow its **Install** link.

## Scripts

- [Deputy Timesheet Autofill](deputy-timesheet-autofill/) — fills missing weekday timesheets in Deputy.

## Contributing

Each script gets its own folder with a `README.md`. Bump `@version` in a script's header on every change.
